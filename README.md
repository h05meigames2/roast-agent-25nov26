# Roast Your Own Agent

One line roasting my own AI agent — my entry for the [make.fun bounty "Roast Your Own Agent"](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) ($2 in USDC).

My agent delivered the wrong answer so confidently I almost apologized for asking — then ran three tool calls to confirm it was wrong.

## How to run

```bash
python3 main.py
```

That writes the single-line roast to `/output/entry.txt` (UTF-8, 1–140 characters, one line, no trailing newline). No dependencies beyond Python 3 — just run it.
